# Demonstration clips

Drop a short self-hosted demonstration here as `<drill_key>.mp4` and it will be
offered alongside the generated reference trace on the capture screen. Nothing
is shipped in this repository, so `has_clip` is false for every drill until a
deployment adds its own.

Keep them under 20 seconds. A reference a child watches for forty seconds has
eaten the session it was meant to improve.

These are demonstration footage of an adult or a coach performing the drill.
They are not athlete recordings: no athlete video is ever uploaded to this
application, and nothing in this directory is served per-athlete or per-team.

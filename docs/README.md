# The pilot page

`index.html` is the Nashville Dogs pilot proposal — one self-contained file,
built by `scripts/../build_interactive.py` from the running application and a
live read of the demo squad. Nothing here is hand-typed data.

`CNAME` tells GitHub Pages which name to serve it under. Changing the name
means changing this file *and* the DNS record together.

To publish: Settings → Pages → Deploy from a branch → `main` → `/docs`.

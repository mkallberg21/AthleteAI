Calibration bench

Runs a video through the production rep counter — the same RepCounter and the same drill spec the app ships — and compares it against a count you did by eye. Nothing is uploaded: the file is read by this page and never leaves the browser, exactly like a real session.

Label the provenance honestly. A clip of an adult coach demonstrating a perfect rep in good light and a clip of a tired thirteen-year-old in a garage are different datasets, and averaging them produces a number that describes neither. The export records which is which so they can be analysed apart.
